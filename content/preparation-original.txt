# Step 01 — একদম Zero থেকে Basics

## 1. Polyphase System কী?

Exam Definition (2 marks):

A polyphase system is a system in which AC sources operate at the same frequency but have different phase angles.

সহজভাবে, একাধিক AC voltage একই frequency-তে কাজ করছে, কিন্তু তাদের phase angle আলাদা—এটাই Polyphase System।

এর মধ্যে Three-phase System সবচেয়ে গুরুত্বপূর্ণ।

## 2. Three-phase System কী?

একটি Three-phase System-এ তিনটি AC voltage থাকে, যাদের মধ্যে phase difference 120°।

ধরো, তিনটি phase হলো a, b, c।

Basic positive-sequence three-phase phasor diagram (abc)

### Why is Three-phase System important? (4 marks)

ম্যামের L-01, page 6-এর চারটি point:

1. Most electrical power is generated and distributed using three-phase systems.
2. Total instantaneous power can be constant.
3. It requires less conductor material than an equivalent single-phase system for the same power.
4. Three-phase motors are generally self-starting.

এই চারটি point পরীক্ষায় সরাসরি লিখতে পারবে।

## 3. Balanced Three-phase System

Definition:

A balanced three-phase system has equal source voltage magnitudes separated by 120°, with equal load impedances in all three phases.

অর্থাৎ:

\\[ |V\_{an}|=|V\_{bn}|=|V\_{cn}| \\]

\\[ Z_a=Z_b=Z_c \\]

এখানে \\(Z\\) = Impedance, যার unit Ω (ohm)।

# Step 02 — Phase Sequence

এটা খুবই গুরুত্বপূর্ণ। তোমার দুইটা lecture-এই আছে।

## 1. Phase Sequence কী?

Exam Definition:

Phase sequence is the time order in which the phase voltages reach their maximum values.

দুই ধরনের Phase Sequence আছে:

| Positive Sequence | Negative Sequence |
| ----------------- | ----------------- |
| abc / RYB         | acb / RBY         |
| a → b → c         | a → c → b         |
| b lags a by 120°  | b leads a by 120° |

### Positive (abc) Phasor

যদি phase voltage 230 V হয়:

\\[ V\_{an}=230\angle0^\circ \\]

\\[ V\_{bn}=230\angle-120^\circ \\]

\\[ V\_{cn}=230\angle+120^\circ \\]

### Negative (acb) Phasor

\\[ V\_{an}=230\angle0^\circ \\]

\\[ V\_{bn}=230\angle+120^\circ \\]

\\[ V\_{cn}=230\angle-120^\circ \\]

মনে রাখবে: Positive-এ b হলো −120°, Negative-এ b হলো +120°, যখন a-এর angle 0° ধরা হয়।

## 2. Sinusoidal Expression

L-01, page 8 অনুযায়ী, positive sequence-এর জন্য:

\\[ v\_{an}=V_m\sin(\omega t) \\]

\\[ v\_{bn}=V_m\sin(\omega t-120^\circ) \\]

\\[ v\_{cn}=V_m\sin(\omega t+120^\circ) \\]

এখানে:

- \\(V_m\\) = Maximum/peak voltage
- \\(\omega=2\pi f\\) = Angular frequency
- \\(f\\) = Frequency

50 Hz হলে:

\\[ \omega=2\pi(50)=100\pi\\;\text{rad/s} \\]

RMS এবং Peak voltage-এর সম্পর্ক:

\\[ \boxed{V\_{rms}=\frac{V_m}{\sqrt3}\\;\text{নয়}} \\]

সঠিক সম্পর্ক:

\\[ \boxed{V\_{rms}=\frac{V_m}{\sqrt2}} \\]

এখানে অনেকেই √2 আর √3 গুলিয়ে ফেলে। √2 ব্যবহার করবে peak-to-RMS conversion-এর জন্য; √3 ব্যবহার করবে balanced Y-এর line-to-phase voltage conversion-এর জন্য।

## 3. Phase Sequence বের করার নিয়ম

L-01-এর page 10–12 অনুযায়ী:

1. Voltage expressions-গুলোকে phasor form-এ convert করবে।
2. Phasor diagram-এ একটি fixed reference point ধরবে।
3. Phasors counterclockwise rotate করলে কোনটি আগে fixed point অতিক্রম করে তা দেখবে।

Special note: L-02 page 3-এ \\(-200\cos(\omega t)\\)-এর sine conversion-এ একটি sign inconsistency আছে। সঠিক identity হলো:

\\[ -200\cos(\omega t)=200\sin(\omega t-90^\circ) \\]

তাই ওই example-এর conversion অন্ধভাবে মুখস্থ করবে না।

# Step 03 — Balanced Y-Y Connection

MOST IMPORTANT NUMERICAL TOPIC

এবার আসি সেই অংশে যেটা PYQ-তে সরাসরি আছে।

## 1. Y-Y Connection মানে কী?

Y-Y means both the three-phase source and the three-phase load are star (Y) connected.

এতে দুটি গুরুত্বপূর্ণ relation:

Line Voltage

\\(V_L=\sqrt3 V_P\\)

Line Current

\\(I_L=I_P\\)

For positive sequence, line voltage leads its corresponding phase voltage by 30°.

## 2. Line Voltage আর Phase Voltage-এর পার্থক্য

| Phase Voltage                  | Line Voltage                  |
| ------------------------------ | ----------------------------- |
| একটি line এবং neutral-এর মধ্যে | দুটি line-এর মধ্যে            |
| \\(V\_{an},V\_{bn},V\_{cn}\\)  | \\(V\_{ab},V\_{bc},V\_{ca}\\) |
| Example: 230 V                 | Example: 398.37 V             |

## 3. Derivation: Prove \\(V_L=\sqrt3 V_P\\)

এটা L-02, pages 8–10-এর গুরুত্বপূর্ণ derivation।

Given: Balanced Y-Y system with positive abc sequence.

Applying KVL:

\\[ -V\_{an}+V\_{ab}+V\_{bn}=0 \\]

Therefore,

\\[ V\_{ab}=V\_{an}-V\_{bn} \\]

\\[ V\_{ab}=V\_{an}+V\_{nb} \\]

The angle between \\(V\_{an}\\) and \\(V\_{nb}\\) is 60°.

Using vector addition:

\\[ V_L=\sqrt{V_P^2+V_P^2+2V_P^2\cos60^\circ} \\]

Since \\(\cos60^\circ=\frac12\\),

\\[ V_L=\sqrt{V_P^2+V_P^2+V_P^2} \\]

\\[ \boxed{V_L=\sqrt3 V_P} \\]

For positive sequence, the resulting line-voltage phasor leads the corresponding phase-voltage phasor by 30°.

Final conclusion (exam-এ অবশ্যই লিখবে):

In a balanced Y-Y system, the magnitude of line voltage is √3 times the phase voltage, and the line voltage leads its corresponding phase voltage by 30° for positive sequence.

For negative sequence, the line voltage lags by 30°.&#x20;

# Step 04 — PYQ Numerical: Complete Solution

এবার তোমার দেওয়া আগের প্রশ্নের Y-connected অংশ solve করি।

Given:

\\[ V\_{ph}=230\\;V \\]

\\[ Z\_{ph}=20\angle30^\circ\\;\Omega \\]

Frequency = 50 Hz

Assume positive (abc) sequence.

## (a) Determine the line-to-line voltages

প্রথমে:

\\[ V_L=\sqrt3\times230 \\]

\\[ V_L=398.37\\;V \\]

তাহলে:

\\[ \boxed{V\_{ab}=398.37\angle30^\circ\\;V} \\]

\\[ \boxed{V\_{bc}=398.37\angle-90^\circ\\;V} \\]

\\[ \boxed{V\_{ca}=398.37\angle150^\circ\\;V} \\]

এখানে \\(150^\circ\\) এবং \\(-210^\circ\\) একই phasor direction নির্দেশ করে।

Phasor diagram আঁকার সময় phase voltage-এর angle 0°, −120°, +120° এবং line voltage-এর angle +30°, −90°, +150° দেখাবে।

## (b-i) Calculate the phase currents

Ohm's law:

\\[ I\_{ph}=\frac{V\_{ph}}{Z\_{ph}} \\]

প্রথম phase:

\\[ I_a=\frac{230\angle0^\circ}{20\angle30^\circ} \\]

Magnitude divide এবং angle subtract করবে।

\\[ \boxed{I_a=11.5\angle-30^\circ\\;A} \\]

একইভাবে:

\\[ I_b=\frac{230\angle-120^\circ}{20\angle30^\circ} \\]

\\[ \boxed{I_b=11.5\angle-150^\circ\\;A} \\]

\\[ I_c=\frac{230\angle120^\circ}{20\angle30^\circ} \\]

\\[ \boxed{I_c=11.5\angle90^\circ\\;A} \\]

Shortcut: Impedance angle +30° হওয়ায় প্রতিটি current নিজ নিজ phase voltage থেকে 30° lag করছে।

## (b-ii) Determine the line currents

For Y connection:

\\[ I_L=I\_{ph} \\]

সুতরাং:

\\[ \boxed{I_A=11.5\angle-30^\circ A} \\]

\\[ \boxed{I_B=11.5\angle-150^\circ A} \\]

\\[ \boxed{I_C=11.5\angle90^\circ A} \\]

এখানে √3 দিয়ে current multiply করবে না।

## (b-iii) Find the total consumed power

এই formula-টি PYQ-এর power অংশ solve করার জন্য standard balanced three-phase power relation; তোমার uploaded slides-এ power derivation আলাদাভাবে দেখানো হয়নি।

\\[ P=3V\_{ph}I\_{ph}\cos\phi \\]

Here,

\\[ \phi=30^\circ \\]

\\[ P=3\times230\times11.5\times\cos30^\circ \\]

\\[ P=3\times230\times11.5\times0.866 \\]

\\[ \boxed{P\approx6872\\;W=6.87\\;kW} \\]

Solved PYQ — Final Answers

| Quantity                | Answer        |
| ----------------------- | ------------- |
| Line voltage            | 398.37 V      |
| Phase current magnitude | 11.5 A        |
| Line current magnitude  | 11.5 A        |
| Power factor            | 0.866 lagging |
| Total real power        | 6.87 kW       |

এই numerical-এর (a) এবং (b) অংশ আগের CT-এর 12 marks বহন করেছিল। এই pattern-এর প্রশ্ন দ্রুত solve করতে পারা তোমার preparation-এর বড় অংশ।

# Step 05 — আরও দুটি গুরুত্বপূর্ণ Proof

## 1. Prove that phasor summation of balanced three-phase voltages is zero

For positive sequence:

\\[ V\_{an}=V_P\angle0^\circ \\]

\\[ V\_{bn}=V_P\angle-120^\circ \\]

\\[ V\_{cn}=V_P\angle120^\circ \\]

In rectangular form:

\\[ V\_{an}=V_P \\]

\\[ V\_{bn}=-\frac{V_P}{2}-j\frac{\sqrt3V_P}{2} \\]

\\[ V\_{cn}=-\frac{V_P}{2}+j\frac{\sqrt3V_P}{2} \\]

Adding:

\\[ V\_{an}+V\_{bn}+V\_{cn} =V_P-\frac{V_P}{2}-\frac{V_P}{2} \\]

The imaginary components also cancel.

\\[ \boxed{V\_{an}+V\_{bn}+V\_{cn}=0} \\]

Similarly, for balanced phase currents:

\\[ \boxed{I_a+I_b+I_c=0} \\]

এই proof-টা L-02-এর pages 4–5-এর একই conclusion প্রতিষ্ঠা করে।&#x20;

## 2. Contribution of Neutral Wire in Y-Y System

ম্যামের L-02-এর pages 13–15 থেকে এটি পড়বে।

For a balanced Y-Y system, considering equal per-phase total impedance \\(Z_Y\\):

\\[ V\_{an}=I_aZ_Y+V\_{Nn} \\]

\\[ V\_{bn}=I_bZ_Y+V\_{Nn} \\]

\\[ V\_{cn}=I_cZ_Y+V\_{Nn} \\]

Adding all three equations:

\\[ V\_{an}+V\_{bn}+V\_{cn} =(I_a+I_b+I_c)Z_Y+3V\_{Nn} \\]

For a balanced system:

\\[ 0=0+3V\_{Nn} \\]

Therefore,

\\[ \boxed{V\_{Nn}=0} \\]

And,

\\[ \boxed{I_n=I_a+I_b+I_c=0} \\]

Important conclusion: In an ideal balanced Y-Y system, the neutral current is zero. However, the neutral wire is useful in practical systems because loads may become unbalanced.&#x20;
